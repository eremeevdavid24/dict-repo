Dicționarele în Python sunt structuri de date care stochează informația sub formă de perechi
cheie–valoare. Fiecare cheie este unică și este folosită pentru a accesa rapid valoarea asociată.
Dicționarele sunt mutabile, adică pot fi modificate după creare (se pot adăuga, șterge sau
modifica elemente). Ele sunt foarte utile atunci când vrei să lucrezi cu date organizate logic,
de exemplu nume și note, setări sau informații despre un obiect.
